Everything below is a placeholder (solid-color / gradient panels generated in
code, not real photography) standing in for assets that don't exist yet.
Drop the real file at the exact path and the layout picks it up with no code
changes.

| Path | Purpose |
| --- | --- |
| `logos/bk-group.svg` | BK Group parent-brand logo (footer / about) |
| `videos/hero.mp4`, `videos/hero.webm` | Cinematic hero background video (falls back to `images/hero/hero.webp`) |
| `videos/background-loop.mp4` | Looping ambient section background |
| `images/hero/hero.webp` | Hero fallback / poster image — Kigali skyline or financial district |
| `images/leadership/*.webp` | Executive & board portraits, one file per person |
| `images/advisors/*.webp` | Investment advisor / analyst portraits |
| `images/services/*.webp` | Investment Mgmt, Corporate Finance, Brokerage imagery |
| `images/investment/*.webp` | Aguka Fund / Tekana Pension product imagery |
| `images/market/*.webp` | Market charts, trading floor, RSE imagery |
| `images/reports/*.webp` | Market report / publication cover art |
| `images/testimonials/*.webp` | Client testimonial portraits |
| `images/offices/*.webp` | KN 30 St, Kigali office photography |
| `images/backgrounds/*.webp` | Section background textures/gradients |
| `icons/*.svg` | Custom icon overrides (Lucide is used by default) |
| `illustrations/*.svg` | Editorial illustrations for empty states / features |

Recommended format: WebP (AVIF where supported), ultra-high-res source,
consistent aspect ratio per section, professionally color-graded — see
project brief for full spec.
